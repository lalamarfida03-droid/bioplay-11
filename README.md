# BioPlay 11

Website belajar Biologi kelas 11 dengan:
- 2 game: Maze Biology dan Bio Battle
- 5 level pada masing-masing game
- soal biologi yang diacak
- keyboard + controller untuk Maze
- latihan soal biasa
- catatan/rangkuman materi
- Pomodoro dengan preset 15/25/45/50 menit + durasi custom

## Cara menjalankan
Buka `index.html` di browser.

## Cara membuatnya online
Upload file `index.html` ke layanan hosting statis seperti GitHub Pages, Netlify, atau Vercel. Karena versi ini hanya memakai HTML/CSS/JavaScript, tidak membutuhkan database/server untuk fitur dasar.

## Catatan
Soal dan rangkuman yang tersedia adalah konten contoh yang dapat kamu kembangkan lagi sesuai buku/kurikulum sekolahmu.
